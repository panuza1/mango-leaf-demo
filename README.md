# Mango Leaf AI

Compare SVM, custom CNN and GoogLeNet on uploaded mango leaf images (8 classes). The Gradio app runs real CPU inference, not simulated predictions.

## Run locally

Use Python 3.11 or 3.12. Copy the trusted trained artifacts from the original project into `models/`:
- cnn.pth
- googlenet.pth
- svm.joblib

Weights and training illustrations are intentionally excluded from this public repository. Obtain them from the project team or the privately supplied demo ZIP. Only load trusted joblib files.

```bash
python -m venv .venv
# Activate the environment before installing dependencies
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:7860.

## Hosting

The Gradio backend requires a Python host with the three checkpoints installed. Set GRADIO_SERVER_NAME=0.0.0.0 and PORT to the host's assigned port. The static site in `web/` can be imported into Vercel (Root Directory: `web`, Framework Preset: Other). Its `vercel.json` configures the build and output directory. Set the project environment variable `MANGO_BACKEND_URL` to the public HTTPS URL of the backend before deploying. The static page embeds the actual Gradio backend; no prediction is generated by the static page itself. A running backend is required.

## Verification and limitations

The original bundled demo was smoke-tested on CPU with all three trained checkpoints. SVM emitted a scikit-learn serialization compatibility warning in the test environment (1.8.0 vs training 1.6.1); requirements specify 1.6.1, but that exact environment has not been verified. The original external test performance was limited; confidence scores are not guarantees. This repository version has not been deployed or browser-tested.

## Docker backend

With the original trusted checkpoints in `models/`:

```bash
docker build -t mango-leaf-demo .
docker run --rm -p 7860:7860 -v "$PWD/models:/app/models:ro" mango-leaf-demo
```

The Docker image intentionally does not contain the model weights. Mount them as private files on the backend host. Configure a public HTTPS endpoint for the service; the Vercel site embeds that endpoint. Docker build and live hosting have not been tested.
